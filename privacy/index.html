Privacy Policy

Last updated: October 10, 2026

This policy covers the AutoYT upload tool run by Dhairya Shah (D'Verse) for the YouTube channel The Loop Hole.

What it does. AutoYT uploads videos to the channel owner's own YouTube channel and reads that channel's video list, using Google's YouTube API with the owner's permission. It requests only the youtube.upload and youtube.readonly scopes.

Data. The tool is used only by its owner. It does not collect data from any other person. It stores an access token for the owner's account in a private, access-controlled repository so uploads can run automatically.

Sharing. No data is sold, shared with third parties, or used for advertising.

Revoking access. Access can be removed at any time at myaccount.google.com/permissions.
