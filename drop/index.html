Security & Architecture details
• Zero-Knowledge: Files and text are encrypted locally in browser memory via the Web Crypto API using AES-256-GCM. The key is in the URL hash and never hits server logs.
• Strict Lifecycles: PostgreSQL Row-Level Security automatically blocks expired or burned drops. Expired storage blobs are purged.
• Safe Downloads: Downloads are served with Content-Disposition: attachment and sandboxed to prevent script execution.
