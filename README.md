# D'Verse Apps (`Dcode9/apps`)

A suite of minimalist web tools and experiments deployed on the D'Verse network:

- **[D-Drop](/drop/)**: Anonymous, ephemeral, zero-knowledge file & text sharing with 6-character access codes, auto-expiration, client-side AES-256-GCM encryption, and burn-after-reading.
- **[PollyText](/pollytext/)**: LLM pollinations arena & text playground.
- **[AuraSlides](/auraslides/)**: AI presentation generator and slide architect.
- **[ImagePlayground](/imageplayground/)**: Generative AI image studio.
- **[Soundboard](/soundboard/)**: High-fidelity soundboard with soundscapes and FX.
- **[Maths](/maths/)**: Interactive mathematical explorer.
- **[Horror Remote](/horror_remote/)**: Real-time synchronized horror SFX player and WebRTC audio remote.
